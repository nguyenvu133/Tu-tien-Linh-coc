# Tu Tien: Linh Coc Demo

Demo game tu tien nguyen ban dung Phaser 4.2.1.

## Cai dependency

Chay tai thu muc `demo/`:

```bash
npm install
```

Dependency runtime duy nhat hien tai la `phaser`, duoc tro toi package Phaser o thu muc cha bang `file:..`. Game dung Graphics cua Phaser nen chua can tai them thu vien asset, physics hoac audio.

## Chay

Mo qua server local tu thu muc goc:

```text
http://localhost:8080/demo/index.html
```

## Kiem tra script

```bash
npm run check
```

Xem [PLAN.md](PLAN.md) de theo doi cac milestone ve asset, music, tu luyen va chien dau.
